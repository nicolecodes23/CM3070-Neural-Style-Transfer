# CM3070 Final Project — Neural Style Transfer
## Project Overview
This repository contains the implementation, experimentation, evaluation, and supporting data for CM3070 Final Project on **optimisation-based Neural Style Transfer (NST)**.

The project investigates how different design choices in Neural Style Transfer influence both the generated images and the preservation of the original content. In particular, the experiments examine the effects of:
- content and style weighting
- optimisation duration and iteration count
- different pretrained VGG architectures
- different artistic style domains
- different optimisation algorithms
- quantitative measures of content preservation and visual difference 
- human perception of the generated results

The project therefore combines deep learning experimentation, quantitative image evaluation, qualitative visual analysis, and human survey evaluation.

The primary implementation is contained in:

`FinalProjectCM3070.ipynb`

This notebook contains the complete Neural Style Transfer pipeline, experimental runs, generated visualisations, stylisation progression images, quantitative evaluation, and experimental analysis.
Because the notebook contains a large number of saved experimental outputs and visualisations, GitHub's built-in notebook preview may not always render the file successfully.
The notebook can be opened directly in Google Colab:[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/nicolecodes23/CM3070-Neural-Style-Transfer/blob/main/FinalProjectCM3070.ipynb)

# Main Project Files

## `FinalProjectCM3070.ipynb`

This is the **core notebook for the project**.

It contains the implementation and experimental investigation of optimisation-based Neural Style Transfer.

The notebook includes:
- loading and preprocessing of content and style images;
- pretrained VGG feature extraction;
- content-loss computation;
- style-loss computation using Gram matrices;
- optimisation-based image generation;
- baseline Neural Style Transfer;
- hyperparameter experiments;
- iteration-budget experiments;
- VGG architecture comparison;
- multiple content and artistic-style combinations;
- optimiser comparison;
- quantitative image evaluation;
- generated-image comparisons;
- stylisation progression visualisations;
- loss and convergence graphs; and
- consolidated experimental results.

The generated images, graphs, stylisation progressions, and other experimental visualisations used in the project are contained directly within the executed notebook.

They are not separately required for execution because they can be regenerated by running the notebook.

# Evaluation

The project uses both **quantitative and qualitative evaluation**.

Quantitative evaluation includes measures relating to:
- content preservation;
- content loss;
- style loss;
- total optimisation loss;
- Structural Similarity Index Measure (SSIM);
- colour-distribution differences;
- convergence behaviour; and
- execution time.

Qualitative evaluation includes visual comparison of:
- different content images with the same artistic style;
- the same content image with different artistic styles;
- different hyperparameter configurations;
- VGG architecture choices;
- optimisation algorithms; and
- intermediate and final stylisation outputs.

A human survey provides an additional perceptual evaluation of selected generated outputs.

# Relationship to the Neural Style Transfer Project Brief

## Final Outcome
The final outcome of the project is both a **portfolio of Neural Style Transfer images** and an **experimental investigation of the relationship between deep-learning configuration choices and generated outputs**.

The resulting portfolio contains stylisations across multiple content images and visually distinct artistic styles and additionally studies how changes in architecture, hyperparameters, optimisation strategy, and style domain influence the resulting images.

Therefore, the output is not only a collection of generated images, but also a systematic experimental evaluation of the behaviour of optimisation-based Neural Style Transfer.

---
## Experimental Extension Beyond the Baseline

Following implementation of the baseline system, the project investigates several extensions and experimental variables.

These include:
- content/style weighting;
- optimisation iteration count;
- VGG16 versus VGG19 feature extraction;
- multiple content-image and style-image combinations;
- Adam versus L-BFGS optimisation;
- quantitative image-quality and content-preservation metrics; and
- human evaluation of generated results.

This allows the project to examine both the technical behaviour of the NST system and the perceptual characteristics of its outputs.
